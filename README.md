# Stream Replay Analyzer

配信アーカイブを見返すとき、コメントが集中した時間帯から探すと、前後の文脈を確かめやすくなります。この Windows 向けのローカルアプリは、録画とチャットを同じ経過秒で表示し、見どころ候補の根拠を示します。Python 3.12、Streamlit、PyAV を使用しています。アカウント、API キー、ローカル LLM は不要です。

## Windows で起動

Python 3.12（64 bit）をインストールし、プロジェクトのフォルダーで PowerShell を開きます。初回の依存パッケージ取得にはインターネット接続が必要です。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501 --browser.gatherUsageStats false
```

ブラウザーで [デモを開く](http://127.0.0.1:8501)。終了は起動したターミナルで Ctrl+C。次回は最後のコマンドだけで起動できます。

## 30 秒で試す

1. 初期画面に同梱の無音 MP4 と日中混在の架空コメント 14 件が表示されます。再生ボタンを押すと、画面の大きな数字で現在秒を確認できます。
2. タイムラインの `00:12 このリズム好き` をクリックすると、動画は 7 秒から再生されます。`00:02` のコメントをクリックすると 0 秒に戻ります。同じ行を繰り返しクリックしても再生位置を戻せます。
3. 下の候補一覧で `00:10 – 00:20`（7 件）と `00:25 – 00:30`（4 件）を確認します。前者では連続する 2 枠がまとまり、代表コメントは 10 秒の「青いラインが伸びてきた」です。

## 自分の録画を使う

「ファイルを読み込む」で MP4 と CSV を 1 つずつ選びます。動作確認には同梱の `demo/replay.mp4` と `demo/chat.csv` も使えます。CSV は UTF-8（BOM 可）で保存します。

```csv
seconds,message
2,時計が動き始めた！
10,"来た, この瞬間！"
12,这一秒很精彩
```

- `seconds` は録画の先頭を 0 とする整数秒です。録画の長さ未満の値を指定します。
- カンマを含む本文は二重引用符で囲みます。時刻順に自動整列し、同じ秒の投稿は入力順を保持します。
- 列名のみならコメント 0 件として動画を表示します。列数、時刻、空の本文、引用符のエラーには該当行を表示します。文字コードが異なる場合は UTF-8 での保存を案内します。
- 個人の素材は `private/` に置けます。このフォルダー全体を Git の追跡対象から除外しています。

## 実装済みの分析

録画先頭から 5 秒ごとの半開区間（例：10 秒以上 15 秒未満）にコメントを集計します。3 件以上の枠を採用し、隣り合う採用枠は 1 候補に結合します。終端は録画時間までです。各候補に採用枠数、コメント総数、代表コメントを表示します。代表は最多投稿枠の先頭コメントで、同数なら早い枠を優先します。

| ファイル | 役割 |
| --- | --- |
| `analysis_core.py` | CSV 検証、再生位置の計算、密度集計と候補の結合。標準ライブラリのみ |
| `app.py` | デモ・アップロードの切り替え、録画時間の取得、分析結果の表示 |
| `player.html` | 動画とコメントを並べ、クリック操作でシーク・再生 |
| `scripts/generate_demo.py` | オリジナルの秒数表示と進捗バーを描画し H.264 MP4 にエンコード |
| `tests/test_analysis.py` | シーク境界、空データ、隣接ピーク、CSV の回帰テスト |

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
# 同梱動画を再生成する場合
.\.venv\Scripts\python.exe scripts\generate_demo.py
```

## 現在の制約

- MP4 は 40 MiB、CSV は 1 MiB までです。動画をメモリに読み込んでブラウザーに渡します。再生可能なコーデックはブラウザーに依存します。デモと同じ H.264 MP4 を推奨します。
- 投稿時刻は録画と同期済みの整数秒に限ります。配信時刻からの変換や遅延補正は未実装です。
- 固定幅・固定件数の集計なので、投稿数の少ない名場面や枠の境界にまたがる短い反応を取りこぼす場合があります。候補は確認用で、動画の切り出し機能はありません。

## 今後の計画

音量変化や画面変化を録画の経過秒に対応する特徴量として抽出し、コメント密度と組み合わせて候補の根拠を表示する予定です。
